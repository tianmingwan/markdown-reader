# 方案：markdown 阅读器功能规划

## 目标

做一个"打开即预览"、资源占用低、跨平台（桌面 + 安卓平板）的 Markdown 阅读器。

## 功能清单

1. 打开文件夹 → 左侧文件树
2. 顶部标签页多文档切换
3. 打开即预览，无需编辑
4. 记忆上次阅读位置
5. 目录自动监听刷新

## 技术选型

| 层 | 选择 | 理由 |
| --- | --- | --- |
| 壳 | Tauri 2 | 体积小、吃内存少 |
| 渲染 | pulldown-cmark + syntect | 全后端、毫秒级 |
| 公式 | KaTeX 按需 | 没有公式的文档零开销 |
| 图表 | Mermaid 按需 | 同上 |

## 风险与对策

- 安卓目录权限 → SAF 授权方案
- 大目录扫描 → 后台线程 + 缓存
